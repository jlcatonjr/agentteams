# `api_impact` — AgentTeamsModule

Detects commits that change the project's API or structure, so the team reviews and updates its API after
each one. The `pre-commit` hook ([`git-hooks`](git-hooks.md)) runs it on the staged diff. The orchestrator's
**API Impact Review** and Workflow 11 gate 6b run `status` over the branch's commits. Contract for generated
teams: `references/api-impact.reference.md`.

> *Source: `agentteams/api_impact.py`*

---

## What counts as impact

| Category | Detected when |
|---|---|
| Modules | a Python module is added, removed or renamed |
| Symbols | a public module-level function or class, a public method of a public class, or `__all__` is added, removed or re-signed |
| CLI | an `add_argument` option string or an `add_parser` subcommand is added or removed |
| Schemas | a `*.schema.json` file is added, removed or modified |
| Structure | any other tracked file is added, removed or renamed |
| Regenerated | a built-in derived artifact was regenerated by the hook |

Test files, and paths under `docs/`, `docs_src/`, `tests/`, `tmp/`, `workSummaries/`, `references/plans/`,
`*/expected/` and the review ledger, are left out of every category. Symbol-level detection reads Python
only.

## Review state

Nothing is stored between runs. `status` walks the non-merge commits from the branch base to `HEAD`:

- **Base:** on a feature branch, the merge-base with the default branch (`origin/HEAD`, `origin/main`,
  `origin/master`, else a local `main`/`master`); on the default branch, `@{upstream}`. No base means
  **pending** (exit 2), never a pass; pass `--range BASE..HEAD`.
- **Reviewed:** the commit's stable patch-id has a ledger file,
  `references/api-impact-reviews/<patch-id>.json`, committed at `HEAD`. The root `references/` is used when
  it exists, else the agent directory's. Patch-ids survive rebase and cherry-pick; a squash merge makes a new
  one.
- **Checklist:** for each removed, renamed or re-signed name, the tracked files that mention it (whole-word,
  the changed file and tests left out, at most 15 plus the total).

`record` writes the ledger files. It is a self-attestation that the ledger makes visible in the pull
request, not proof that a review happened.

## Pre-commit

`pre_commit()` prints one line summarizing the staged impact and never fails. In the agentteams repository,
after the operator opts in with `git config agentteams.regenerateMan true`, it regenerates `agentteams.1`
and stages it when `build_team.py`, `agentteams/cli/` or `agentteams/man.py` is staged and has no unstaged
edits.

## CLI

```
python -m agentteams.api_impact --pre-commit [--repo DIR]
python -m agentteams.api_impact detect (--staged | --commit SHA) [--json]
python -m agentteams.api_impact status [--range BASE..HEAD] [--json]   # 0 reviewed, 1 pending, 2 no base
python -m agentteams.api_impact record [--range BASE..HEAD] --note TEXT
```

## Key functions

### `surface(source: str) -> dict[str, str] | None`

The public surface of one module: functions, classes, public methods, `__all__`, `cli:<option>` and
`cli-cmd:<subcommand>` entries mapped to signatures. `None` when the source does not parse.

### `detect(repo: Path, *, commit: str | None = None) -> Impact`

The impact of the staged index (`commit=None`) or of one commit, as an `Impact` dataclass with one list per
category, an `impactful` property and `summary()`.

### `ledger_dir(repo: Path) -> Path`

Where review records live.

### `resolve_base(repo: Path) -> str | None`

The range start for `status`, or `None` when none can be found.

### `patch_id(repo: Path, commit: str) -> str`

The commit's stable patch-id from plumbing (`diff-tree -p --no-ext-diff --no-textconv`), ledger excluded.

### `status(repo: Path, rev_range: str | None = None) -> tuple[str | None, list[CommitStatus]]`

`(range_used, commits)` for every impactful commit in the range.

### `record(repo: Path, note: str, rev_range: str | None = None) -> list[Path]`

Writes a ledger file per unreviewed impactful commit; raises `ValueError` on an empty note or a missing base.

### `pre_commit(repo: Path) -> str`

The hook's step; returns the message it prints.

### `main(argv: list[str] | None = None) -> int`

CLI entry point.
